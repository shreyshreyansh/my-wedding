# Ram Mandir wedding invitation

A responsive React and Vite recreation of the Ram Mandir wedding invitation, including its decorative artwork, typography, motion, RSVP flow, countdown, gallery, bells, waving flag, bird flock, and interactive venue map.

## Run locally

```sh
npm install
npm run dev
```

## Verify

```sh
npm run typecheck
npm test -- --run
npm run build
npm run verify:assets
npm run test:visual
npm run test:e2e
```

The visual suite checks the measured reference geometry at 393px, 412px, 469px, and 1440px viewports.
